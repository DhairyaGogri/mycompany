# Projects update — change log

## What changed
- Replaced the single-style project presentation with a data-driven project portfolio.
- Added six verified portfolio entries based on the existing public portfolio and linked GitHub repositories.
- Added four clearly labelled illustrative public-sector case-study templates for future editing.
- Added procurement-relevant fields: client/provenance, sector, challenge, solution, outcome, technologies and procurement relevance.
- Added accessible client-side filtering with `aria-pressed` states and a live result count.
- Added responsive card/metadata/filter styling without changing the site's overall visual system.
- Updated the evidence register, README and testing guide so the distinction between verified evidence and illustrative content remains explicit.

## Why
- Gives buyers a clearer view of breadth without making unsupported client or contract claims.
- Makes real work easier to assess against public-sector concerns such as accessibility, reliability, data quality, maintainability and value.
- Provides reusable case-study templates that can be converted into genuine references once client names, dates, measures and permissions are available.
- Keeps the site's existing HTML/CSS/vanilla-JS architecture intact.
